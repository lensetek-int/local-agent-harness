# 📚 完整指南：通过本地 RAG 录入 SOP 规程文档（无需二次训练）

本指南详细说明如何将**标准作业程序（SOP）**、工业设备操作手册、技术规程或医疗急救指南录入 **Lensetek Edge AI** 边缘智能体系统中。

> [!IMPORTANT]
> **您的 AI 模型已完全定型，即开即用（`lensetek-edge-loop-3b-q4_k_m.gguf`）。**  
> 添加或更新企业内部 SOP 文档时，**完全不需要**对模型权重进行任何重新训练或微调（Fine-Tuning）。所有专业知识均通过内置的 **EdgeRAG（轻量级本地 SQLite 检索增强生成引擎）** 实现动态、即时注入。

---

## 🌟 为什么采用 RAG 而非重新训练模型？

1. **秒级即时生效（< 2 秒）**：上传 SOP 文档后，智能体立即可依据该文档回答规程问题。
2. **标定零幻觉（Zero-Hallucination）**：Lensetek-Edge-Loop-3B 模型经过严格对齐，仅根据本地检索到的文档事实答复；若文档缺失，严格如实拒答，杜绝捏造参数引发生产事故。
3. **极简维护与版本更新**：企业 SOP 修订（如 2026 版更新至 2027 版）时，只需在界面删除旧文档并上传新文件即可，无需消耗任何昂贵的 GPU 算力。
4. **100% 离线脱网与数据主权**：所有文档均在本地计算与存储（`knowledge_rag.db`），绝不向公网或云端发送任何企业机密数据。

---

## 📄 支持的 SOP 文档文件格式

内置解析提取引擎自动支持以下常见格式：
* **电子文档**：`.pdf`（官方红头文件、设备出厂技术说明书、规程汇编）
* **文字处理**：`.docx`（Word 格式的规程草案与作业指导书）
* **纯文本与标注**：`.txt`、`.md`（技术排查检查清单、Markdown 流程笔记）
* **结构化表格与日志**：`.csv`、`.json`、`.log`（传感器报警阈值、故障代码字典）

### 方法一：通过 Web Studio 可视化界面（操作员首选）

1. **启动服务**：
   双击 `start.bat`（或在终端运行 `py app.py`）。
2. **访问浏览器**：
   在浏览器中打开：[`http://localhost:3000`](http://localhost:3000)。
3. **打开知识库窗口**：
   在顶部导航栏右上角，点击绿色按钮 **`📚 Dokumen RAG`**。
4. **上传 SOP 文档**：
   * 将您的 `.pdf`、`.docx` 或 `.txt` 文件直接拖拽至上传区域，或点击选择本地文件。
5. **系统自动处理**：
   * 系统自动将长文本按语意切分（Chunks），并通过纯 NumPy 向量引擎构建索引并存入 `knowledge_rag.db`。
   * 界面提示 `✓ Berhasil diindeks`，并显示字符数与分块数量。
6. **开始提问**：
   * 关闭知识库弹窗，确保输入框旁的 RAG 开关显示为 **`✓ Aktif`**。
   * 直接向模型提问，例如：  
     *“根据 SOP 规程，GEN-09 锅炉机组的安全运行压力上限是多少？”*  
     模型将严格按照您刚才上传的 SOP 内容进行精准解答！

### 方法二：通过命令行自动化脚本（`py ingest_sop.py`）

非常适合工程师以及一次性批量导入多份规程手册：

#### 1. 录入单份 SOP 文件
```bash
py ingest_sop.py 工业锅炉运行规程.pdf
```

#### 2. 批量录入整个文件夹中的所有 SOP
将所有规程文档放在同一个文件夹内（如 `./sop_docs`），然后执行：
```bash
py ingest_sop.py --folder ./sop_docs
```
*执行输出示例：*
```text
[INFO] 在 'C:\...\sop_docs' 中找到 6 个规程文档...
  [✓] 索引成功: 工业锅炉运行规程.pdf (12 个分块)
  [✓] 索引成功: 车间安全应急预案.docx (8 个分块)
  [✓] 索引成功: 临床急救处置指引.pdf (15 个分块)
[✓] 处理完成: 6/6 个文件已成功注入本地 RAG 知识库！
```

#### 3. 查看当前已索引的 SOP 文档列表
```bash
py ingest_sop.py --list
```

#### 4. 直接测试文档语意检索（无需启动大模型推理）
```bash
py ingest_sop.py --search "锅炉压力上限"
```

#### 5. 清空知识库所有文档（重置数据库）
```bash
py ingest_sop.py --clear
```

### 方法三：通过 REST API 接口（`/api/rag/upload`）

适用于将本地 AI 与现有工厂制造执行系统（MES）、企业资源计划（ERP）或自动化机器人系统对接：

* **接口地址**：`POST http://localhost:3000/api/rag/upload`
* **内容类型**：`application/json`

#### 直接发送纯文本格式规程：
```bash
curl -X POST http://localhost:3000/api/rag/upload \
  -H "Content-Type: application/json" \
  -d '{"filename": "燃气轮机检修SOP.txt", "text": "轴承持续运转温度严禁超过摄氏 75 度，振动幅值超过 4.5 mm/s 时必须立即紧急停机。"}'
```

#### 发送 Base64 编码的 PDF / Word 二进制文件：
```json
{
  "filename": "医疗急救方案.pdf",
  "content_base64": "data:application/pdf;base64,JVBERi0xLjQKJ..."
}
```

## 🔄 SOP 规程版本更新与维护

当企业更新 SOP 文件时：
1. 打开 Web Studio 界面的 **`📚 Dokumen RAG`** 弹窗。
2. 点击旧版 SOP 旁的 **删除（垃圾桶图标）**。
3. 拖入新版 SOP 文件。
4. **完成！** 无需重启服务，智能体将立即遵循最新版规程输出答案。
