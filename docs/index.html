THE ARCHITECTURAL DIFFERENCE

Why Conventional Harnesses Fail on SLMs — And Why Lean Works

Most agent frameworks were built for massive 100B+ cloud API models with 128k context windows. On small edge models (SLMs), their heavy token overhead causes instant failure. Here is the realistic engineering behind our lean edge-first approach.

Conventional Frameworks Cloud-First / API-Centric

LangChain, CrewAI, AutoGPT, OpenHands

  • ❌
    Massive Initial Token Bloat (4,000 – 8,000+ tokens)

    Injects verbose JSON schemas, dozens of tool definitions, and dense few-shot examples into the system prompt before the user even types a single word.

  • ❌
    Context Collapse & Hallucination on SLMs (3B Models)

    Small language models suffer from attention dilution and context saturation. They hallucinate non-existent tool arguments, emit malformed JSON, or freeze in infinite loops.

  • ❌
    Heavy Infrastructure & Tool Dependencies

    Often requires Docker daemon, Redis message queues, external vector databases, and massive Node.js/Python dependency trees just to boot.

  • ❌
    Cloud Cost & Privacy Leakage

    Requires ongoing paid cloud API tokens (OpenAI / Anthropic). Private code, proprietary data, and prompts are continuously streamed to third-party cloud servers.

Lensetek Lean Harness Edge-First / Autonomous

Purpose-Built for Local SLMs & Local LLMs

  • ✅
    Ultra-Lean Token Budgeting (< 350 tokens initial prompt)

    Minimalist ReAct instruction set. Leaves >90% of the context window wide open for actual user prompts, file contents, and step-by-step reasoning.

  • ✅
    Runs Edge SLMs (3B) with Scalability to Local LLMs (7B / 14B)

    Flawlessly drives 3B edge models on modest hardware, yet instantly scales to 7B or custom local models via /model switch and /model add.

  • ✅
    Zero GPU Requirement & Low RAM (< 2.5 GB)

    Optimized for commodity CPUs (everyday laptops, mini PCs, SBCs). Pure GGUF execution with 8-bit KV cache compression without requiring discrete GPUs.

  • ✅
    Built-in Anti-Hallucination & Loop Circuit-Breakers

    Small models can spiral when a tool fails. Our harness includes runtime interceptors and retry caps that detect failure patterns and rescue the agent.

  • ✅
    100% Air-Gapped & True Data Sovereignty

    Runs entirely offline with zero cloud telemetry. Your source code, sensitive documents, and prompt thoughts never leave your local machine.

🎯
Realistic Edge Positioning: We don't claim to replace trillion-parameter cloud clusters with 200 microservices. Our mission is distinct: delivering a truly autonomous, lightweight AI agent harness that actually executes reliably on everyday edge devices and local small models without breaking your RAM, budget, or privacy.

Slash Commands Reference

Type / and press Tab in the CLI to see instant completions.

Command Category Description
/help SYSTEM Displays comprehensive guide of all slash commands and capabilities.
/language <en|id|cn> CONFIG Switch agent response & prompt language (English, Indonesian, Chinese). Saved persistently.
/model [add|switch] MODEL List local models (3B, 7B), switch active model, or register custom paths with /model add <path>.
/search <query> WEB Perform an instant headless web search directly from the prompt.
/skills [filter] SKILLS Browse and filter available local and custom domain skills.
/skill create <name> SKILLS Create and save a new custom domain skill in cli-agent/skills/.
/<skill-name> [task] SKILLS Execute a specific skill guide directly with anti-hallucination protection.
/mcp [install|test|remove] MCP Manage and install Stdio MCP servers with runtime credential injection.
/goal <objective> AGENTIC Launches multi-step goal solver (up to 20 steps) with context resilience.
/loop <3x|5m> <task> AGENTIC Repeat a task with automatic context reset to avoid token degradation.
/schedule <add|list> SCHEDULER Schedule tasks via in-app timer daemon or OS Task Scheduler (Windows/Linux/macOS).
/strict | /auto-approve | /yolo SAFETY Toggle workspace execution confirmation level on the fly.
