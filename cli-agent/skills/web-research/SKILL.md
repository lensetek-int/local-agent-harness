# 🌐 Web Research Skill

Gunakan skill ini saat mencari informasi dari internet:
1. Utamakan memanggil tool MCP `fetch` (jika tersedia) untuk mengambil konten web dalam format Markdown bersih tanpa membebani browser GUI.
2. Jika butuh navigasi interaktif atau JavaScript dinamis, gunakan tool MCP `playwright-headless` atau `chrome-devtools`.
3. Rangkum informasi penting langsung ke inti jawaban dan sertakan URL sumber jika relevan.
4. Hindari membaca halaman berukuran raksasa sekaligus untuk menghemat context window.
